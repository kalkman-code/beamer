# Beamer RU Test 1.5.14-ru.2

Экспериментальная локальная доработка Beamer, а не официальный выпуск автора проекта.
Связанные запросы: https://github.com/kalkman-code/beamer/issues/47 и
https://github.com/kalkman-code/beamer/issues/48. Изменения подготовлены с помощью
Codex и предлагаются для проверки автору основного проекта.

Основа: https://github.com/kalkman-code/beamer, коммит
`324edd5731bcff9c28229c0c8a54d547c1b2af29`.

## Что добавлено

- Русский каталог всех 1224 строк текущего интерфейса: меню, настройки, статусы,
  сообщения об ошибках, подключение и инструкции первоначальной настройки.
- «Русский» в выборе языка; автоматическое определение `ru-RU`, `ru_RU` и `ru`.
  Ручной выбор сохраняется после перезапуска.
- Настройка «Синхронизировать русскую и английскую раскладки» на странице «Клавиатура».
  По умолчанию выключена. Включать нужно на обоих компьютерах.
- Включённый режим передаёт выбранный язык при переходе управления и перед вводом
  клавиш. Пока ввод передаётся другому компьютеру, отдельное нажатие Alt+Shift
  переключает RU/EN через Beamer. Сочетания с дополнительной клавишей, включая
  AltGr+Shift при вводе символа, передаются обычным способом.
- Windows разрешает символы по раскладке активного окна, а не рабочего потока Beamer.
- Если язык не удаётся выбрать, приёмник показывает сообщение. Ошибка выбора
  раскладки не останавливает обычную обработку клавиш; повторные попытки ограничены.

Синхронизация поддерживается только между обновлёнными версиями. Со старым Beamer
новый режим не отправляется. Выбираются только уже включённые/установленные системные
раскладки; приложение не устанавливает языки. Если есть несколько раскладок одного
языка, текущая подходящая сохраняется, иначе выбирается первая подходящая в системном
списке. Отдельного редактора соответствий раскладок в этой версии нет.

## Mac с Apple silicon

Готовое приложение находится в архиве `Beamer-RU-Test-Mac-AppleSilicon-ru.2.zip`.

1. Завершите обычный Beamer через его меню.
2. Распакуйте архив. Можно скопировать **Beamer RU Test.app** в «Программы» рядом
   с обычным Beamer: имена приложений различаются.
3. Откройте тестовое приложение. Оно использует отдельные настройки
   `~/Library/Application Support/Beamer RU Test/settings.json` и журнал
   `~/Library/Logs/Beamer RU Test/Beamer.log`.
4. На странице «Разрешения» предоставьте доступ именно тестовому приложению и
   перезапустите его, если об этом попросит Beamer.
5. Если интерфейс не русский, выберите «Русский» в настройке языка на странице
   «Подключение» и перезапустите приложение. «Автоматически» следует языку системы.

Сборка предназначена для Apple silicon, подписана локальной ad-hoc подписью,
не имеет нотариализации Apple. Обычный установленный Beamer не заменён.
Возврат к нему: завершите тестовое приложение и откройте обычное.

## Windows: запуск исходников

В архиве `Beamer-RU-Sync-Source-ru.2.zip` есть полный исходный код обеих версий.

1. Распакуйте весь архив в доступную для записи папку.
2. Нужен установленный стабильный 64-разрядный Python 3.12 или новее с доступной
   командой `python`. Официальный сайт: https://www.python.org/downloads/windows/.
3. Завершите обычный Beamer.
4. Дважды нажмите **Run-Test-Windows.cmd**. При первом запуске он создаст локальное
   окружение `.venv-test` и установит зависимости из PyPI; нужен интернет.
5. Тестовые настройки будут в `test-data/settings.json` внутри распакованной папки.
   Существующее сопряжение обычной версии в них не копируется: выполните тестовое
   сопряжение заново. Правила брандмауэра эти командные файлы не меняют.
6. Для русского интерфейса используйте язык системы или выберите «Русский» вручную
   на странице «Подключение», затем перезапустите приложение.

**Build-Test-Windows.cmd** проверяет выбранные тесты и собирает `dist-windows/Beamer.exe`
с помощью PyInstaller. После успешной сборки Run-Test-Windows.cmd будет запускать этот
файл с теми же отдельными настройками. Сборка EXE на настоящей Windows здесь ещё
не выполнялась. Командные файлы Windows подготовлены, но на Windows не запускались.

Обычные Install-Beamer.ps1 и Install-Beamer-Mac.command из исходного проекта
устанавливают приложение поверх обычной версии; для этого первого теста используйте
описанные выше отдельные способы запуска.

## Проверка на двух компьютерах

1. Запустите обновлённые тестовые версии на Mac и Windows, выполните сопряжение.
2. Убедитесь, что в системе каждого компьютера включены русский и английский ввод.
3. Включите синхронизацию раскладок на странице «Клавиатура» на обоих компьютерах.
4. Выберите русский ввод на Mac и английский в Блокноте Windows. Перейдите с Mac
   на Windows и введите `южэхъ`. Проверьте русский индикатор Windows и результат:
   ожидается `южэхъ`, а не `.;'[]`.
5. Во время удалённого управления нажмите левый Alt+Shift, введите английский текст,
   затем снова переключите язык. Проверьте возврат на Mac и направление Windows → Mac.
6. Проверьте Ctrl/Cmd+C, Alt+Tab/Cmd+Tab, заглавные буквы, удержание и отпускание клавиш.

Этот сценарий на реальной паре Mac–Windows ещё не проверен. Это тестовая реализация;
прохождение автоматических проверок не подтверждает работу на всех приложениях и
вариантах раскладок. Без проверки на вашей Windows полноценную готовность утверждать нельзя.

## Проверки и воспроизведение сборки

Результаты конкретных запусков — в `TEST-RESULTS.txt`. Проверены логика протокола,
владение вводом, обработка Alt+Shift/AltGr и модификаторов, сохранение настроек,
полнота каталога, размещение русского текста и запуск собранного Mac-приложения.
Windows API в тестах проверялись через подставной интерфейс; Qt-окна проверялись
на Mac без вывода на экран. Пользователь подтвердил работу на реальной связке Mac–Windows, включая RU/EN и Fn. Автоматические Windows API тесты на Mac используют подставной интерфейс; эта проверка не охватывает все конфигурации Windows.

Mac-приложение можно повторно собрать на Mac из окружения Python с зависимостями
`mac_app/requirements-mac.txt` и `pyinstaller`:

```sh
python -m pip install -r mac_app/requirements-mac.txt pyinstaller
python tools/build_test_mac.py
```

Результат — `mac_app/dist-preview/Beamer RU Test.app`. Это отдельный локальный
сборочный путь. Официальный универсальный сборщик проекта остаётся в mac_app/build_dmg.sh.

## Дополнение ru.2: клавиша Fn на Mac

При включённой синхронизации на обоих компьютерах отдельное нажатие и отпускание Fn на Mac переключает RU/EN при управлении Windows. Сочетания Fn с другими клавишами не переключают язык. Alt+Shift продолжает работать. Windows с версией ru.1 совместима, обновлять её для Fn не требуется.
